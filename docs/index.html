SECS, repackaged

Propose molecular structures from a molecular formula and one processed one-dimensional proton (1H) NMR spectrum.

This service repackages SECS, the work of Adrian Mirza, Luc Patiny, Kevin Maik Jablonka, and upstream contributors. We did not develop the scientific methods or train the supplied model. Our work connects them to the NMR API, handles uploaded spectra, and supports reproducible deployment, with adaptations maintained in pinned forks.

We also used the upstream GUI, elucidation.cheminfo.org (source), as a reference for spectrum conversion and published challenge fixtures. Our conversion tests use outputs from a pinned revision of its frontend. The GUI is a separate application, not the interface to this API provider; its supported inputs and results may differ.

Submit a job

You need access to an NMR API deployment that offers SECS. Use the client supplied by its operator; ask the operator for the client address and access if you do not have them. This page is documentation, not an upload form.

Choose the SECS provider and the analysis kind mol_from_1h_spectrum_formula. Attach a supported spectrum and put its molecular formula in the job instructions. If SECS is not listed, ask the deployment operator whether it is available.

For every job, a language-model interpreter receives the job instructions and attachment descriptions to choose the spectrum, reader, and formula. It can also inspect archive listings and excerpts from attached files. These are sent to the deployment's configured language-model service; check with the operator before submitting confidential information.

Supported uploads

  • Bruker: upload a ZIP containing a processed pdata directory. Keep 1r and procs together in the same directory; include title if available. That directory can be at the ZIP root or inside preserved experiment folders. 1r alone is insufficient: procs supplies the spectrum metadata and ppm axis.
  • JCAMP-DX: upload a file directly or inside a ZIP. Supported representations are a processed 1H AFFN XYDATA block with a ppm axis, or an NTUPLES real/imaginary pair with a ppm axis or a referenced Hz axis.

Raw time-domain data (FID), spectrum images, and peak lists are not inputs to this analysis. Upload processed spectral data, not a screenshot.

Example: a Bruker experiment

For the strychnine example files used by our Bruker regression test, ZIP F3697/1/pdata/1/, including 1r, procs, and title. Attach that ZIP and write:

Analyse the sole processed 1H spectrum in the attached ZIP.
Molecular formula: C21H22N2O2.

If you upload several files or experiments, explain which sample and experiment you intend. The interpreter explains its selection in the result; check that it chose the experiment and formula you intended.

What the result means

SECS retrieves candidates from a molecular index and refines them with a genetic algorithm. The result includes ranked candidate SMILES (text representations of molecular structures), scores, the selected input and formula, selection explanations, and search settings.

Higher scores rank better within a search; they are not probabilities that a structure is correct. These are candidates for chemical review, not validated structure assignments. The example above demonstrates input preparation, not a guarantee of recovering strychnine.

A completed search can return no candidates. If retrieval finds no starting molecules, the result records no_starting_candidates and explains that refinement did not run. This is a limit of that search, not proof that the formula is invalid or that no matching structure exists.

If the interpreter cannot select usable input, the attempt fails with cannot_analyse: no analysis was produced. Its failure message includes the interpreter's explanation. That explanation is the model's account, not proof that a reader ran or that your spectrum is invalid. The deployment operator retains the full report and recorded rejection reasons under the attempt identifier. Older attempts may show this outcome as a successful result; that did not mean structures were found.

A failed attempt reports an error or interruption, for example an outage or an interpretation limit. It does not establish whether computation finished. Read its failure message and share the job and attempt identifiers with the deployment operator if you need help. Do not assume that it means the spectrum is invalid, or that selection history will be available.
